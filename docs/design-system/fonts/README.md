# Font Assets

Self-hosted variable WOFF2 subsets from Google Fonts. No remote font request is made at runtime. Latin and Latin Extended subsets cover the mock text in Portuguese and English.

| `dmsans-latin.woff2` | DM Sans | latin | [Google Fonts file](https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K4.woff2) |

| `manrope-latin.woff2` | Manrope | latin | [Google Fonts file](https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2) |

Keep each family’s accompanying `*-OFL.txt` license when copying these files. `styles/fonts.css` preserves the supplied unicode ranges and weight ranges, with `font-display: swap`. Additional scripts require corresponding font subsets.
