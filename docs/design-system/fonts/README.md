# Font Assets

The admin loads local Barlow Condensed Bold, IBM Plex Sans (400–700) and IBM Plex Mono (400, 600 and 700) from this directory. The home wordmark uses the local Anton assets in `src/assets`. No runtime font request is required.

The Barlow and IBM Plex files were obtained from Google Fonts and use the SIL Open Font License. See `barlow-OFL.txt` and `ibm-plex-OFL.txt`; the Anton license is in `src/assets/anton-OFL.txt`. Previous font files remain for historical static assets.
