# Admin Design Context

The canonical visual system is [Admin Design System](docs/design-system/DESIGN.md). Read it together with [tokens](docs/design-system/tokens.md), [layouts](docs/design-system/layouts.md), and [components](docs/design-system/components.md).

Import docs/design-system/styles/index.css once. Reuse its semantic variables and local fonts. The existing light palette, DM Sans body, Manrope headings, control geometry, focus treatment, and reduced-motion behavior remain authoritative. Preserve canonical colors rather than introducing a second palette or converting existing values for this task.

Login uses the product register and the existing restrained visual language. Specification 004 defines its proposed page composition and states. It does not change canonical tokens or the reference mocks.
